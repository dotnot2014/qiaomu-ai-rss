- 修复语音朗读「无法连接 Edge 语音服务」：该服务要求 User-Agent 必须是真实 Edge，而页面级 WebSocket 的 UA 由浏览器写死、无法覆盖，因此改为在插件内通过 Node 的 ws 建立连接（桌面端），并保留 101 握手与真实音频的端到端验证。
- 新增「AI 总结」：正文工具栏一键总结当前阅读的版本，可切换速览、要点、结构、金句四种样式，按文章缓存并支持重新生成。
- 新增语音朗读（桌面端）：总结卡片上的喇叭按钮用 Microsoft Edge 在线语音朗读当前样式，11 种音色、5 档语速，设置页可试听；合成结果按文本缓存。
- 设置新增独立的「AI 总结」标签页，支持任意 OpenAI 兼容接口（Base URL、API Key、模型），并提供连接测试。
- 未配置接口时不发送任何请求；文章纯文本仅发送到你指定的服务，语音朗读只发送总结文本。
